# 概要
初級コーディング課題であるフラワーショップサイトの静的コーディングを実装

# 実施内容
- HTML/CSSによる静的サイトの構築
- レスポンシブデザイン対応（PC/タブレット/SP）
- Top, Concept, Gallery, News, Shopの各セクション実装
- Google Fonts導入（EB Garamond, Noto Sans JP）
- ホバーエフェクトの実装
